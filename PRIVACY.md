# Privacy Policy — Bitcoin Ticker (+Widget)

**Last updated: 2026-08-24**

Bitcoin Ticker (+Widget) ("the app") is developed by Simon Kirschner.

## Data collection

The app collects, stores, transmits, or shares **no personal data whatsoever**.

- No accounts, no registration
- No analytics, no tracking, no advertising SDKs
- No crash reporting services
- No cookies
- No access to contacts, location, files, camera, microphone, or any other
  sensitive device data

## Network communication

The app only makes anonymous HTTPS requests to public market-data endpoints
to fetch the current Bitcoin price:

- CoinGecko public API (api.coingecko.com)
- Coinbase public API (api.exchange.coinbase.com) — fallback
- Blockchain.com (blockchain.info) and Frankfurter (frankfurter.app) —
  historical chart data only

These requests contain no personal identifiers beyond what any HTTPS request
technically exposes (IP address, standard headers) and are governed by the
respective providers' privacy policies.

## Permissions

The app requests no Android permissions beyond internet access and the
standard widget/scheduling capabilities required for a home-screen widget.

## Donations

The app contains a link to an external PayPal donation page
(paypal.me/SimonKirschner). Opening it is entirely optional and happens only
on an explicit tap, in your browser. PayPal's own privacy policy applies to
anything you do on that page.

## Changes

Any future change to this policy will be documented in this file and in the
app's release notes.

Questions: open an issue on the app's public source repository.
